功能亮点

围绕真实开发切换点设计，而不是围绕功能清单堆砌

Termflow 把最常发生的中断点变成可管理的界面对象：会话、输入、提交、对比、命令与主题。每张卡片都对应一个实际的开发动作。

01

多会话管理

把不同项目、不同阶段和不同目标拆分成清晰会话。切换时保留上下文，不再因为共用一个终端窗口而丢失思路。

02

语音输入

需求太长、灵感太快、双手还在别的窗口里时，直接说。语音输入以轻量悬浮态出现，不让工作台失焦。

03

Git 面板

把提交摘要、改动文件、风险提醒和提交动作放在一个面板里，减少在多个工具之间的碎片化跳转。

04

检查点审阅

关键阶段被保存为可回看的节点。你可以快速对比“之前”和“现在”，减少重复解释与重复试错。

05

快速命令

高频动作不必重复输入。常用命令入口保持靠近当前工作区，让操作像呼出工具，而不是重新找路。

06

4 套主题

不是简单换肤，而是为不同光照、演示和长时间工作准备更稳定的阅读与焦点节奏。

07

会话持久化

长任务不会因为重开窗口而失忆。Termflow 让你的上下文停留在桌面本地，而不是重新从头解释。

08

多语言支持

在多语言团队和跨语种资料场景下保持自然工作，不必为了界面语言切换开发节奏。

09

桌面技术栈

基于 Tauri 2、React 19、Rust 与 TypeScript 构建，让桌面体验、性能与工程组织保持同一个方向。

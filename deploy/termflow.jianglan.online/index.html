Termflow

让智能体工作流
留在你的桌面。

Termflow 是一个本地桌面工作台，将 CLI 智能体、终端、代码编辑与 Git 工作流整合到同一个项目上下文中。

多智能体协作

在同一项目中管理多个 CLI 智能体会话，专注推进真实工作。

终端与代码

终端、文件编辑、Markdown 与 PDF 预览并排协作，无需频繁切换工具。

Git 工作流

查看状态、提交、分支、历史与差异，把变更留在清晰可控的项目上下文中。

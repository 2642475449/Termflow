## 新增与升级

- 新增定时任务管理：可创建和管理计划任务、查看运行记录，并从侧边栏进入任务面板。
- 任务监控增强为按项目汇总，补充 Antigravity 用量数据展示，便于集中查看智能体运行状态与额度。
- 终端支持粘贴图片附件，并提供剪贴板缓存管理、路径插入和命令完成通知配置。
- Git 冲突面板可直接打开冲突解决视图，减少在冲突处理流程中的切换操作。

## 问题修复

- 修复 Windows 环境中智能体 Hook 路径编码可能导致的执行异常，并改进空音频等异常输入的处理。
- 修复 Git 冲突视图的类型定义和差异视图接入，确保冲突文件能正确打开和处理。
- 改善终端附件保存与插入流程，避免重复处理并保持附件路径可用。

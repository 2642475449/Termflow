## 新增与升级

- 项目快捷命令支持随项目迁移：终端命令与智能体提示统一保存在 `.termflow/quick-commands.json`，可集中查看不同项目的命令，并支持选择脚本、查看和停止运行中的命令。
- 新增项目启动组合：在标题栏编辑 `.termflow/launchers.json`，预览后一次打开多个普通终端，各终端可指定项目相对工作目录和命令；配置不会自动执行，不包含工作区模板或项目默认智能体设置。
- 新增语音整理配置，支持选择服务商、模型与连续文本、分段或结构化整理方式，并加强整理结果校验；优化语音按钮、状态提示和界面动效。
- 增强智能体集成：新增 Codex Hook 激活状态检测，接入 Pi 生命周期状态与会话用量统计，统一智能体配置路径解析。
- 文件编辑支持识别文本编码并按相应编码保存，统一压缩文件图标；改善主题、终端配色与任务状态展示。
- 项目切换器支持选择位置创建新项目目录；Git 变更列表增加将路径加入 `.gitignore` 的操作。

## 问题修复

- 修复多个项目窗口保存状态时可能相互覆盖旧会话快照的问题，改为按项目合并持久化数据。
- 修复实时语音启动期间无法及时取消或长时间等待的问题，增加启动超时处理；改善语音悬浮胶囊偶发不显示及文本过长溢出的问题。
- 改善终端输出帧与输入法输入期间的显示稳定性，并同步普通终端命令运行状态。
- 修复项目子目录终端的归属与工作目录混用问题，使关闭项目时能够正确回收终端，并正确解析初始目录下的文件链接。
- 修复 Codex 重置额度解析中的 Rust 类型错误，保证发布构建通过。

## 升级说明

- 已有本机项目快捷命令会在打开项目时迁移到 `.termflow/quick-commands.json`；全局命令继续保存在本机。需要团队共享时，将项目配置文件提交到 Git。
- `.termflow/local/` 用于个人本机文件，请在自己的项目中将其加入 `.gitignore`。启动组合使用本机默认终端，命令需与该 Shell 兼容。

## 新增与升级

- 新增计划任务管理与后台运行设置：可集中创建、查看和管理计划任务，并在关闭窗口后按设置继续运行任务。
- 编辑体验升级：文件选区可直接发起侧边提问，新增 TextMate 语法支持；全局搜索支持多行关键词、可调整窗口大小及 Monaco 结果预览。
- Git 工作流增强：差异视图支持图片内容，冲突处理入口和提交图展示得到改进；资源管理器支持剪切并移动文件。
- 设置中增加 MCP 服务器管理入口，并改善智能体任务状态、用量与会话标题的展示。

## 问题修复

- 修复终端并发输入可能交错的问题，改为按顺序发送输入内容。
- 修复语音快捷键录制、Git 冲突文件打开及差异视图中的若干交互问题。
- 改进智能会话标题生成，使标题更准确地概括任务意图，避免直接摘录用户原话。

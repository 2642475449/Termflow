## 新增与升级

- Git 面板统一主要操作入口：有文件更改时优先提交，没有文件更改时根据本地与远程提交数量显示推送、拉取或同步；下拉菜单保留提交并推送、提交并同步等操作。
- Git 远程更新检查并入刷新按钮及后台自动刷新，支持请求去重、刷新节流和失败提示；远程配置、上游分支设置与分支发布集中到更多菜单。
- 新增按项目分组的智能体任务监控，可查看已打开任务的运行状态。
- 智能体设置新增版本检查和更新状态，详情中集中展示安装信息、额度、重置时间及安装命令。
- 语音输入接入后端实时转写会话，完善录音、转写结果与停止操作之间的衔接。

## 问题修复

- 修复项目切换和异步刷新可能导致 Git 分支、文件状态混用的问题，并区分仓库读取失败与非 Git 项目。
- 加强 Git 提交、推送和同步的串行执行及分支校验；提交成功但远程操作失败时保留并明确显示部分成功结果，避免误判提交失败。
- 修复修改远程地址后仍使用旧跟踪状态的问题；重新获取远程数据前阻止基于旧状态执行同步。
- 修复 Git 修改与删除冲突的处理，完善同步遇到本地更改时的处理流程。
- 改善最近项目及已打开项目的状态同步，并修复再次打开项目时窗口未正确恢复到前台的问题。
